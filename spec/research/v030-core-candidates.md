# Three additions after v0.3.0

D67 approved all three for Minimal and Core in v0.4.0. These comparisons describe the v0.3.0 games that prompted each change. The [player guide](../docs/16-game-changes.md) and [author guide](tutorial-library.md) describe how to use them.

| Feature | Behavior in v0.3.0 | Design and reason |
|---|---|---|
| **Check TM compatibility before paying** in Minimal and Core | At a Mart or the Game Corner prize counter, INFO describes the move. The teaching menu checks each party member after the player has the machine. In SameBoy, neither INFO page for TM01 in a Red Core or Minimal Mart showed who could learn Mega Punch. | Show which current party members can learn the machine or already know its move. The price, use count and teaching rules stay the same. A player can avoid spending money or coins on an unusable TM. [Party list](../../engine/menus/party_menu.asm) · [Teaching rules](../../engine/items/item_effects.asm) |
| **Preview another box at Bill’s PC** in Minimal and Core | The box chooser shows occupancy. Confirming a box saves the game and selects where the next boxed catch goes. | From the PC, inspect species and nicknames in a highlighted box and back out. Viewing must leave the active box and the save untouched. Read the active box from memory so catches since the last save appear. In a new game, unopened boxes must appear empty even if the cartridge holds an older adventure. [Box chooser](../../engine/menus/save.asm) · [Save regression](box-picker-safety.md) |
| **Give an individual trainer Pokémon a custom moveset** in either author base | Authors can set species and levels in the party data. Gym leaders, the Elite Four and the Champion have separate code for signature moves. Ordinary trainer rows have no general moveset field. | Let an author give one Youngster’s Pokémon a move without changing any other Youngster or the trainer AI. Existing teams must produce the same moves, PP and battle behavior by default. Test the edited trainer in battle alongside an untouched trainer of the same class. [Current loader](../../engine/battle/read_trainer_party.asm) · [Crystal's trainer format](https://github.com/pret/pokecrystal/blob/9ce4c4e5068ffdf56e23ca3d8dc9178b2465d482/engine/battle/read_trainer_party.asm#L83-L89) |

In v0.3.0, teaching found the first machine mapped to a move. In v0.4.0, teaching and INFO both use the selected machine’s own learnset bit. Two machines can now teach the same move to different species. Tests cover this case, a full Bag, six party members and cancellation. [Compatibility lookup](../../engine/items/tms.asm)

For a developer who wants a mix of presets, independent build switches for selected Core changes would also help. The two battle display switches provide a working example. Starting with v0.5.0, the Move Deleter can be selected separately, including the Route 14 dialogue. The EXP.ALL field switch follows the Core preset. [Build settings](../../Makefile) · [Field switch](../../text/Route15Gate2F.asm)
