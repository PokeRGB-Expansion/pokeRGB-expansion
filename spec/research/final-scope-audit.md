# Final preset and release-scope review

The public Core release includes the entire accepted Core, including improvements shared with Minimal. Implementation order is an internal choice. The [release gate](../docs/09-roadmap.md#what-counts-toward-core) says which records must close and how to demonstrate that a release candidate meets them.

## What moved

The sweep reviewed all **94 archived bug reports**, all **66 existing usability cases**, **25 playthrough decisions**, **16 menu cases**, the **40 mechanics contracts** and the **117-entry tutorial inventory**. It also checked the donor and architecture decisions, the color variants, the save and link plans, and the public documentation. These registers overlap. Their counts measure coverage, not the number of distinct game changes. The current usability register includes the accepted move-learning reader as UC-74. ## Player-facing decisions

**Core notice for a newly full box (UC-69).** On a successful catch or PC-bound gift that fills the selected box, add its number and full status to the existing system transfer notice. Preserve the giver’s dialogue and require no extra confirmation. Test 18→19 and 19→20, a failed throw and a party arrival. Only identify the box that actually filled. Both presets still refuse a later throw when the party and selected box are full. [Stock capture notice](https://github.com/pret/pokered/blob/ba9c0568f64ae602fadda577a08c66639f93082a/data/text/text_6.asm#L37-L49) · [Stock gift notice](https://github.com/pret/pokered/blob/ba9c0568f64ae602fadda577a08c66639f93082a/data/text/text_5.asm#L83-L93)

**Both presets when reopening the Pokédex (UC-70).** Reopen the browsing list at the last row the player visited in the same play session. Start a new game or freshly loaded save at the ordinary opening position. In both retail colors, a seeded Pokédex opened at the top, moved to the ninth list position, restored the caller’s previous scroll offset on exit, then reset to the top on reopening. Keep the two cursors separate. Keep seen/owned restrictions, wrap behavior, habitat sources and automatic registration on capture. Do not jump to a hidden encounter or forecast a new entry. The existing tutorial demonstrates demand for the feature. [Stock entry and exit](https://github.com/pret/pokered/blob/ba9c0568f64ae602fadda577a08c66639f93082a/engine/menus/pokedex.asm#L1-L45) · [Author tutorial](https://github.com/pret/pokered/wiki/Make-the-Pokedex-Remember-Your-Position)

**Day Care moves and fees (UC-71).** Both presets preserve the attendant’s lines, the fee quoted at pickup and the original order for learning moves. With four moves, a Pokémon loses the move currently in slot one. If there is room, it keeps its existing moves. The Kanto remake also keeps the move rule without an advance explanation from the attendant. The developer reference documents these details. [Original games and remake](day-care-history.md)

**Depositing the only conscious Pokémon (UC-72).** Keep the original PC and Day Care deposit flow in both presets. Stock accepted the deposit when another member had 0 HP, as well as when it had 1 HP. An extra warning is a proposal for authors who want one. Preserve the existing refusal for a one-member party and the Day Care’s separate HM check. FireRed added a refusal for the only conscious member. [Stock and remake checks](day-care-history.md)

**Hidden coins that exactly fill the case (UC-73).** A 10-coin pickup at 9,989 credits all ten, marks the pickup claimed and reports dropped coins. At 9,990 only nine fit. Both presets should select the existing ordinary pickup message when every awarded coin fits and the existing spill message when coins were lost. Keep the cap and one-time flag. The paid clerk is separate. CAT-057’s change to the encoded 40-coin award remains Core only. [Stock pickup](https://github.com/pret/pokered/blob/ba9c0568f64ae602fadda577a08c66639f93082a/engine/events/hidden_items.asm#L73-L119) · [Existing messages](https://github.com/pret/pokered/blob/ba9c0568f64ae602fadda577a08c66639f93082a/data/text/text_2.asm#L764-L783)

**Two required readouts.** Both presets show how many of the selected item are already in the bag when buying, and current/max PP for the selected party move when choosing a PP-restoring item. Count duplicate bag stacks, exclude the PC, respect PP Ups and read the party record the item actually changes. Their integrated screens still need testing. [UC-67/68 and test cases](player-experience-sweep.md)

## Boundaries worth keeping

| Area considered | Decision |
|---|---|
| Battle balance | Keep ordinary Gen 1 critical hits, unified Special, fixed-damage immunities, trapping and wake turns. Core applies its named repairs and data changes. The Focus Energy rounding choice is now settled and checked in a compiled prototype. [Threshold audit](critical-hit-analysis.md) |
| Information and puzzles | Keep undiscovered species, hidden Tower identities and the Snorlax Flute puzzle intact. Live type overlays, move advice, DVs and encounter forecasts are planned developer features. |
| Storage and team building | Manual boxes stay in both named defaults. Keep original trade evolutions, HM move slots, the bag cap and the consequences of forgetting a move. Direct MOVE, automatic box selection, larger inventories and a move relearner remain distinct author choices. |
| Sound, flashes and controls | Lower flashing and a shorter low-HP warning are planned as separate author options. Keep the battle-entry shapes and low-HP sound timing that carry information or affect other waits. Preserve cartridge presentation in the reference builds. [Accessibility evidence](accessibility-scope.md) |
| Downstream game creation | Make alternate rosters, trainer roles, movesets and rules selectable without copying story scripts. For generated runs, validate that each supported roster supplies the required starter, trainer and progression roles. Distinguish the run seed from the battle RNG. These are authoring tools and optional game systems. [Paired editions](emerald-rogue-builds.md) · [Tutorial library](tutorial-library.md) |

This audit preceded implementation. The [release checks](../docs/07-testing-ci.md#verified-reference-configurations) record which save, link and cartridge configurations have since been tested. [Green’s presentation](../docs/06-build-variants.md) documents the released artwork.
