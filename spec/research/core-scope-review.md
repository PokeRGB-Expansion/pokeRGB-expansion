## Which fixes belong in the presets

Minimal keeps the shipped battle rules and resource limits and shares the safeguards approved for it. Equivalent action shortcuts can qualify under D54. A repair to text, sound, or graphics qualifies when equivalent actions with controlled rolls yield the same gameplay state. Core also fixes demonstrable gameplay errors when the original game supplies strong evidence for the expected result. A broken check, contradictory instructions, or a transaction that takes payment and loses the reward can supply that evidence. Later games provide corroboration. Disassembly comments are modern annotations. The explicitly protected Gen 1 rules and agreed usability improvements still apply. Extended gives developers modern systems and keeps unified Special as the preferred starting point, including for hacks that add types or species.

### Transform and Swift

**Core should make Transform fail against a target in the invulnerable turn of Fly or Dig.** The Red/Blue routine tests the exact invulnerability bit and has a failure path. On the player's turn it tests the user's status. On the enemy's turn the accumulator holds the side number, 1, when it tests bit 6. Neither path reads the target's invulnerability at that point. In stock Red and Blue the faster target successfully entered Fly or Dig, the bit was set at Transform's test, and Transform succeeded in all eight hidden-target fixtures. All four grounded controls succeeded. This supports a narrow inference about the move's intended target check. No original developer statement was established. Check normal Transform, Substitute, copied moves/PP/stats, and both link roles when implementing it. Keep the separately scoped transformed-capture repair below. [Source and evidence](evidence.md#e123) · [Recorded tests](core-scope-checks.json)

**Swift keeps its English Red/Blue behavior in Minimal and Core.** Its own return occurs before the Fly/Dig and accuracy checks. All eight hidden-target fixtures took damage, as did the four grounded controls. Standard type immunity still applies. The Japanese Red/Green routine places this bypass inside a Substitute check. Its position changed in English Red/Blue. The Japanese Red/Green and English Yellow Transform routines, by comparison, contain the same defective status reads as English Red/Blue. ## Coverage and release status

The review screened the 94 archived bug topics, 66 usability records, 25 playthrough notes, and the earlier 18-project donor comparison. It traced selected high-confidence findings on upstream revision ba9c0568 and compared stock English Red and Blue in SameBoy 1.0.5 in original Game Boy mode. Disposable parties, moves, map context, HP and PP were set in memory. The normal battle menus and turn routines then ran. For Fly/Dig tests, the target was faster. Execution tracing sampled the target flag at the move's check. For Struggle the observation was the branch to forced Struggle or the move list. For ghosts it was the seen bit before the encounter and at the first battle menu. These 58 single-player cases describe stock behavior.

The gym check separately decoded the linked table and evaluated the original byte operations for 15 rows × 256 byte values × two colors (7,680 modeled cases). Only eight even indices are reachable as the first switch with the normal selector. For can 4, inputs divide equally between 0 and 7 by byte count. This does not measure the distribution of random bytes during a playthrough. The in-game clue, map coordinates, and neighbor table all support adjacency.
